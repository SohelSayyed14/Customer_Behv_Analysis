# Data Analytics Project

## 1. Overview
This project focuses on analyzing a dataset using Python, SQL, and Power BI to extract meaningful insights and support data-driven decision-making.

The project includes data loading, exploratory data analysis (EDA), data cleaning, SQL queries, dashboard development, and reporting.

## 2. Dataset
- Dataset used: customer_shopping_behaviorCSV
- File Format: CSV 
- Description: The dataset is used to perform data analysis and identify trends, patterns, and insights.

## 3. Tools & Technologies
- **Python:** Data loading, cleaning, and EDA.
- **Pandas & NumPy:** Data manipulation and analysis.
- **Matplotlib & Seaborn:** Data visualization.
- **SQL:** Data querying and analysis using PostgreSQL.
- **Power BI:** Interactive dashboard development.
- **Gamma:** Project presentation.

## 4. Steps Performed
1. Loaded the dataset into Python.
2. Performed initial data inspection.
3. Conducted Exploratory Data Analysis (EDA).
4. Cleaned and transformed the data.
5. Performed SQL queries to answer business questions.
6. Created an interactive Power BI dashboard.
7. Prepared the final project report.
8. Created a project presentation using Gamma.

## 5. Dashboard
The Power BI dashboard provides interactive visualizations, key performance indicators (KPIs), and meaningful insights from the dataset.

## 6. Results & Insights
- Identified important trends and patterns in the dataset.
- Analyzed key metrics and performance indicators.
- Generated insights using Python and SQL.
- Presented findings through an interactive Power BI dashboard.

## 7. How to Run
1. Clone or download the repository.
2. Install the required Python libraries.
3. Load the dataset into Python.
4. Run the Jupyter Notebook for data cleaning and EDA.
5. Execute SQL queries in your selected database.
6. Open the Power BI `.pbix` file to explore the dashboard.
